Features to Build in v1.1
1. Chat Messaging
Anyone can type a message and send it. It appears as a bubble.
My own messages appear on the right in blue. Other people's messages appear on the left in grey.
System messages (like "Attendance finalized" or "Leave approved") appear centered in a soft grey bubble.
Messages show the sender's name above the bubble and the time below it.
The chat auto-scrolls so the newest message is always visible at the bottom.
2. Taking Attendance (The Star Feature)
When a teacher types "take attendance" or "/takeattendance" in the chat, the app posts a special message in the chat — an Attendance Card.
This card shows a grid of all the Active students (not Withdrawn ones). Each student appears as:
Their colored initial circle
Their preferred name underneath
A status dot and label: Present (green), Absent (red), Late (yellow), or Excused (blue)
Everyone starts as Present. The teacher just clicks a student to cycle through the statuses: Present → Absent → Late → Excused → back to Present.
At the bottom of the card is a "Done" button. When clicked, the attendance is finalized. The card updates to show it is finalized. A system message appears: "Ms. Homer Yolanda finalized attendance — 14 present, 1 absent, 1 on leave."
The finalized attendance card stays in the chat history. Anyone can scroll back and see it.
3. Leave Requests (Also Through Chat)
When anyone types something like "I'm sick today" or "I need leave tomorrow" or uses "/applyleave", the app detects this and posts a Leave Card in the chat.
The Leave Card shows:
Person's name
Leave type (Sick, Personal, Family, etc.)
Date
Reason
Status: Pending (with Approve and Reject buttons underneath)
Only teachers and admins can see the Approve/Reject buttons. When a teacher clicks Approve, the card updates to show "Approved" in green. A system message confirms it.
4. The AI Assistant
There is a special user in every room called "Heyya Assistant" (or just "Assistant"). It has a robot-style avatar.
The Assistant automatically does helpful things:
When attendance is opened, it says: "Good morning! Attendance for Grade 10 Class 03 is now open."
When attendance is finalized, it summarizes: "Attendance complete: 14 present, 1 absent. All good!"
When someone mentions being sick, it offers to create a leave card.
It can answer simple questions like "Who is on leave today?" by looking at the data.
For v1.1, the Assistant doesn't need to be connected to a real AI API. Just make it respond with smart pre-written messages based on what the user types. Use simple keyword matching.
5. The Mates Panel
The right sidebar lists all Mates in the room, grouped by:
Teachers (at the top)
Students (below)
Each mate row shows:
Their colored initial circle
Their name
Their role (Main Teacher, Co-Teacher, or blank for students)
A green dot if online, grey if offline
For students on leave: a small "On leave" label in orange
Clicking on any mate opens a little profile popup showing:
Their full name
Their email
Their parent name and parent email (for students)
Their enrollment status
Their school ID
6. Excel Upload
I, as the app owner, need to be able to upload an Excel file to add or update student data. Add a simple upload area — maybe a button in the top bar or a drag-and-drop zone.
When I upload the Excel file, the app should:
Read the file
Show me a preview of the first 3 rows
Tell me how many students it found
Let me click "Import" to add them to the room
If there are errors (like duplicate emails or missing names), show me which rows have problems
The Excel format it should expect is the same as the student table above. The app should be able to handle both .xlsx and .csv files.
